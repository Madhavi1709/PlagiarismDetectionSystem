# 📄 Plagiarism Detection System Using Python

## 🔍 Overview
This project detects **plagiarism between two text documents** by calculating
their similarity using **TF-IDF Vectorization** and **Cosine Similarity**.

---

## ⚙️ How It Works
1. Takes two input texts
2. Converts text into numerical vectors using TF-IDF
3. Computes cosine similarity score
4. Interprets plagiarism level based on the score

---

## 🛠️ Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
